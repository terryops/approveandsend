# Approve & Send

**AI 起草，你批准，你的每一次修改都在教它。**

[English](README.md) · 简体中文

一个会自己写回复、但绝不替你发出去的客服邮箱。邮件进来，回复已经写好等着你，你读一遍
——想改就改——然后点发送。真正值得跑它的是接下来那一步：你改动的地方会变成一条规则，
下一封草稿就已经知道了。

![审阅页面：左边是待审队列，中间是可以直接改的草稿，右边是它读懂了什么](docs/images/review.zh-CN.png)

## 它能做什么

- **每一封回复的初稿都由它来写**，用你的说话方式、你的事实，以及它到目前为止学到的
  全部东西。
- **从你的修改里学。** 同一个问题你改过两次，就不会有第三次。它学到的每一条规则都要
  你点头才生效，写的是人话，你随时可以改，也随时可以停用。
- **把噪音挡在桌子外面。** 推广邮件和 no-reply 的通知根本不会进入待办；同事已经手动
  回过的邮件会被跳过；同一条对话上后来的邮件，会让它追上的那份旧草稿退场。
- **告诉你哪几封要当心**——生气的客户、涉及政策的问题、可能是你们这边的 bug——好让
  常规的那些快速过掉。
- **知道自己在写给谁。** 动笔之前，它可以先查清这位客户付过多少钱、你在卖什么，以及
  上一次你们是怎么答复他的。
- **替你读你看不懂的语言。** 每一封来信和每一份草稿都可以在原文旁边显示成你的语言，
  于是你能批准一封本来根本读不了的邮件。
- **从你已经发出去的邮件里学。** 把发件箱指给它，它会先研究你的团队一直以来是怎么
  回的，然后才开始写新的。

## 为什么值得用

**没有人点头，什么都发不出去。** 全自动离「一句写错的退款答复赔掉全部省下的时间」
只有一步之遥。这里的每一封回复都先由人读过——这是产品本身，不是一个可选项。

**它会越来越懂你这份工作。** 靠的不是换个更强的模型，而是你的规则：从你的修改里学来，
以你能读、能改的句子摆在你面前。

**它是你的。** 跑在你自己的机器上、你自己的邮箱上，你的客户往来信件不会躺在别人的
服务器里。

**完全免费，而且彻底开源。** MIT 许可，每一行都是。不用注册账号，不按人头收费，没有
付费版，也没有藏着不给你的托管版本。唯一要花钱的是 AI 模型——而如果你已经在付
ChatGPT 或 Claude 的订阅，或者你在自己的机器上跑模型，那这笔也已经省了。

> **状态：v0.1。** 整条链路是完整的，但还没有跑在任何一个生产环境里。它脱胎于一个
> 私人工具，那个工具处理过 929 封邮件、学到 213 条规则；而这份重写版，除了作者本人
> 没有人用过。

## 怎么把它跑起来

所有技术性的内容都在 **[MANUAL.zh-CN.md](MANUAL.zh-CN.md)** 里——怎么安装、怎么接上
邮箱、怎么挑模型，以及全部配置项。

**你不用自己读它。** 用一个 AI 编程助手打开这个项目——Claude Code、Codex、Cursor，
你顺手的哪个都行——让它替你做配置。比如这么说：

```
读一下这个仓库里的 MANUAL.zh-CN.md，帮我把 Approve & Send 配置好。
需要什么就问我——邮箱、想用哪个 AI 模型——一次问一个，
并且说清楚每个答案是干什么用的。
```

它会读完手册，问你那几个必须问的问题，把配置写好，然后告诉你什么时候可以打开应用。
以后哪里出了问题，同样这一招还管用：把你看到的现象告诉它，让它去翻手册。
